# Patching as a Service - Linux Server

07.05.2025, 17:30 (Europe/Berlin), Hybrid/Hochschule Karlsruhe, Gebäude LI, Hörsaal HE  
Sprache: Deutsch  

Dieser Vortrag zeigt warum Linux Server und Docker Container regelmäßig und möglichst zeitnah mit Betriebssystems-Updates versorgt werden sollten und wie dmTECH das mit praktisch keinem laufenden Aufwand für alle Linux Server implementiert hat. dmTECH betreibt die gesamte IT des dm-Konzerns für 14 Länder und dort u.a. “business-critical”-Systeme für den gesamten Konzern mit über 4000 Filialen und einem Online-Shop in mehreren europäischen Ländern. Dieser Vortrag richtet sich an technisch fortgeschrittene oder versierte Linux-Anwender und Systemadministratoren, die den BSI-Grundschutz umsetzen wollen und die ihre Linux Server möglichst zeitnah und mit wenig Aufwand stets mit aktuellen Sicherheits-Updates versorgt haben wollen.
